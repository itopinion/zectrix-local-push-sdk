# Zectrix 3.7.5 更新说明

相比 3.7.3，本次更新重点优化功耗和日常使用体验：

- **待机更省电**：优化待机功耗，减少空闲时不必要的后台唤醒。
- **远程连接更方便**：支持从设备端连接管理端，改善远程使用的稳定性。
- **待办操作更顺手**：优化列表排序和完成后的选中位置，修复远程提醒无法确认完成的问题。
- **页面显示更清晰**：改善备忘录、天气等页面的文字布局，减少内容挤压、重叠和裁切。
- **音频体验更好**：支持更长的远程录音与播放，优化人声和提示音效果。
- **日常使用更稳定**：改善 Wi-Fi 连接、天气定位和数据同步，修复部分异常重启问题。
