# 固件升级

**简体中文** | [English](FIRMWARE.en.md) | [返回首页](../README.md)

官方升级入口：[ZECTRIX Wiki](https://wiki.zectrix.com/zh/software/firmware) → Note 4 → [极趣云本地升级](https://cloud.zectrix.com/)。本仓库不分发固件或刷写工具。

本 SDK 快照配套 **Note 4 固件 3.7.2**。本版支持色板与灰阶传输协议。未来版本应核对官方兼容说明，不仅比较版本大小。

1. 用 Chrome / Edge 登录极趣云，进入“本地升级”。
2. 用支持数据传输的 USB 线连接 Note 4，点击“连接设备”，选择对应串口。
3. 选择匹配的 Note 4 固件版本并点击“加载”；确认型号、版本及页面要求的语言选项。
4. 需要保留 Wi-Fi 等配置时，按页面勾选“保留设备数据（免重新配网）”。
5. 确认后点击“开始刷写”，等待终端明确显示完成，再重启设备。期间保持供电、页面打开及电脑唤醒。
6. 升级后，在设备的“设置 → 网络同步”中启用“待机保持 Wi-Fi”功能。

如果页面没有所需版本，先向官方确认可用的匹配版本，不要改刷 Note 4C 固件。SDK 仓库不执行或触发升级。

本说明核对于 2026-10-19；页面名称与可选版本以官方 Wiki 和极趣云当前页面为准。
